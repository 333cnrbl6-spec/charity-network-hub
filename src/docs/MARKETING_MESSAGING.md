## FAQ for Marketing

**Q: How is CharityHub different from Salesforce?**  
A: Salesforce is built for enterprise sales teams. CharityHub is built for charities: simpler setup, 10x cheaper, features designed for nonprofits (Gift Aid, compliance, donor engagement).

**Q: Do I need technical skills to use it?**  
A: No. If you can use Excel, you can use CharityHub. It takes 15 minutes to set up.

**Q: Can I import my data from another system?**  
A: Yes. We support CSV, JSON, and direct imports from most platforms (Salesforce, HubSpot, Constant Contact, etc.).

**Q: Is my data secure?**  
A: Yes. We encrypt all data at rest and in transit. Daily backups. Compliance with GDPR, UK Charity Commission standards.

**Q: Can I use CharityHub on mobile?**  
A: Yes. Native apps on iOS and Android. Log donations, view reports, manage campaigns on the go.

**Q: What happens when my trial ends?**  
A: You'll get email reminders at day 28, 29, 30. If you don't upgrade, your account goes read-only (you can still access data). No auto-charge.

**Q: Do you have an API?**  
A: Yes. Professional and Enterprise tiers include full REST API for custom integrations.
